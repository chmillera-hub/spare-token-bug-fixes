# Other collections

This folder holds links to public GitHub collections made by other people which the author of this repository may check again later or ask an AI chatbot to read and verify later.

> **About this page:** An AI chatbot (Claude) wrote the descriptions on 24 November 2026 after reading the front page of each collection and the chatbot did not verify any claim inside the collections which means each description repeats what the collection says about itself.

- [Solved conjectures](https://github.com/1337isnot1337/solved-conjectures) is a collection of about 200 math results (proofs and examples that show a guess is false and partial results) in number theory and graph theory and counting problems and the front page says that a person and an AI model wrote the results together and that no outside reviewer has checked the notes although many results carry a status label for a check by the proof-checking program Lean 4.
- [Navier-Stokes](https://github.com/tristanbuckmaster/navier-stokes) holds a 79-page paper dated 20 November 2026 which claims that a solution of the Navier-Stokes fluid equations can grow without limit in a finite amount of time and the collection includes about 600000 lines for the proof-checking program Lean 4 while the front page says that the numerical data behind the paper has not been released yet.
- [The Tea Ride](https://github.com/ChetasLua/the-tea-ride) is an animated film of about 82 seconds that plays in a web browser from one file and shows a person drinking tea while riding a giant pelican and the film is listed here as an example of a single-file animation with music made by the program itself because the collection holds a film and not research findings.
