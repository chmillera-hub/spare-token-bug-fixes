# Old

This folder holds two early programs that the repository owner does not expect to use again and the programs stay here because a curious visitor may still want to look at the rough early stages.

- [program-1-letters.html](program-1-letters.html) is the first method where copying agents build text one letter at a time.
- [program-2-single-words.html](program-2-single-words.html) is the second method where copying agents build text one whole word at a time.

Each program runs in a web browser after downloading.
