# Bible quote builder

This folder holds an experiment where short phrases from the World English Bible are shuffled by programs and an AI model (Claude) then connects the phrases into short replies under rules that Charles set one at a time.

Warning about a wording change: Charles replaces the name "yahweh" with the word "god" everywhere in the Bible programs and in the newer results as a personal reading choice that helps Charles follow the quotes which means the quotes differ from the World English Bible at every place where the World English Bible prints the name and a reader who wants the original wording can open the World English Bible itself.

Warning about changed wording in the joined Bible passages: the passages that the AI model joined by hand for the Claude Bible set and My Personal Bible set and the Jesus Bible set are not exact Bible quotes because Charles set rules that allow added words and changed pronouns and replaced names and added punctuation which means a reader who wants the exact wording needs to open the World English Bible itself.

## Start here

- [best-outputs.md](best-outputs.md) holds only the finished paragraphs with no commentary and the file named best-outputs-spaced.txt holds every one of the same paragraphs without italics for copying and puts an invisible blank character on its own line between paragraphs for apps that drop empty lines when text is pasted.
- [rules.md](rules.md) lists all forty-nine rules now in force with the reason for each rule.
- [prompt-for-new-chat.txt](prompt-for-new-chat.txt) is a ready-made prompt that a person can paste into a new chat with an AI model so that the AI model can make outputs from any input sentence.
- The public link to the chat on 11 November 2026 where a new chat used the ready-made prompt to make three outputs about Gen Z and work is https://claude.ai/share/e599b4d3-3058-46f9-b138-9f3dd71d925c and those three outputs are copied in full into the three best-outputs files.

## How the experiment developed

- [how-outputs-evolved.md](how-outputs-evolved.md) shows one sample output from each stage so that a visitor can watch the outputs change from noise into readable paragraphs as Charles added rules.
- [full-record.md](full-record.md) is the full record which holds every rule and every passage in the order the rules were added.
- [single-word-stage.md](single-word-stage.md) reports the earlier stage where copying agents built strings out of single words from three Bible selections.
- [john-10-remixes.md](john-10-remixes.md) holds three remixes of John chapter 10 where the chapter was dealt at random into four piles and each pile was turned into one readable paragraph.
