# Prime richness

This folder holds computer counts of how often prime numbers show up in the outputs of different recipes compared with plain counting numbers of the same size. An AI model (Claude) ran the counts and wrote the pages on 21 November 2026 and no other person has rechecked the pages. Each result is written as a percentage against the number line such as +564% for an equation with many primes or −100% for an equation with no primes.

- [new-findings.md](new-findings.md) keeps the results that a quick web search did not turn up which cover dividing a square or a cube and dropping the decimals plus the pieces of a prime read from the right end and read backward plus 467 primes where every reversed piece is prime plus the sum of 1 over each Fibonacci prime and the page ends with a list of related results that a quick search already answers.
- [ranked-list.md](ranked-list.md) is a master list that ranks 423 equations and running sums from the most primes down to no primes (−100%) and covers whole-number equations plus running totals with the bump rule plus trig functions and custom rounding rules and modulus and calculus and the digits of constants such as π. Each line shows how many outputs were tested and the wobble on the percentage and the odds that plain luck explains the result.
- [grouped-list.md](grouped-list.md) holds the same 423 lines sorted into 17 groups by type (such as equations that start with n² or sums and running totals or recipes built from π) with a ranking inside each group.
- [equation-list.md](equation-list.md) ranks 86 equations by how many primes the outputs contain and gives the raw counts and the reason for each percentage where a reason is known.
- [checker.html](checker.html) is a page where a visitor types an equation such as n^2 + n + 41 and reads the predicted percentage against the number line plus a live computer count.
- [champions-467.txt](champions-467.txt) is a plain text file that lists all 467 primes where every reversed piece is prime with one prime on each line.

The checker runs in a web browser at this address: https://chmillera-hub.github.io/spare-token-bug-fixes/1-research-click-here-first/prime-richness/checker.html
