# Word evolution

This folder holds an experiment where text is copied with small mistakes over and over while a reader picks which copies survive.

- [word-evolution-experiments.md](word-evolution-experiments.md) reports what happened in the experiments.
- [try-the-word-evolution-program.md](try-the-word-evolution-program.md) explains two ways to run the live program with sliders and ten separate agents.
- The file named word-evolution-live-program.html is the program itself and runs in a web browser after downloading.
