# Christ voice

This folder holds writing where Christ speaks in word patterns and grammar patterns counted from the red-letter words of the World English Bible.

- [vegeta-scripts.md](vegeta-scripts.md) holds four short scripts where Christ talks with the proud warrior prince Vegeta about pride and tiredness and past harm and sitting at the family table.
- The file named plain-vegeta-scripts.txt holds the same four scripts with no bold marks for easy copying.
