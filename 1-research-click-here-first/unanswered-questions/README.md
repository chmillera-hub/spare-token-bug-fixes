# Unanswered questions

This folder holds experiments where an AI model (Claude) looked for a question that people asked in public and that nobody had answered and then tried to answer the question with research or computing.

- [number-list-mistake.md](number-list-mistake.md) reports a checkable mistake in a published number list (OEIS A394252) plus eight corrected terms and a short proof.
- [turkish-para.md](turkish-para.md) gives a partial answer to when the Turkish para coin stopped being money (the last para coin left circulation in 1950).
- [first-case-claim.md](first-case-claim.md) checks a 2026 medical letter that calls itself the first reported case of patchy hair loss on migraine prevention drugs and finds four earlier database reports.
- [logline-word-origin.md](logline-word-origin.md) answers a question nobody replied to on the Wiktionary word-origin board about whether the screenwriting word logline comes from a sailing rope (the dictionary record points to television program logs and a first use in 1982).
- [urljoin-safety.md](urljoin-safety.md) answers a Python help forum question with zero replies about whether the Python function urljoin can be tricked into pointing at a different website (the tests show the trick works with a tab character).
- [sentinel-typing.md](sentinel-typing.md) answers a Python help forum question with zero replies about a "nothing was passed" marker that type checkers reject and shows a substitute that two type checkers accept.
- [rdflib-two-prefixes.md](rdflib-two-prefixes.md) answers an open GitHub question with zero comments about why the linked data library rdflib keeps only one nickname for a web address.
- [animation-y-limit.md](animation-y-limit.md) answers a matplotlib forum question with zero replies about a y limit that would not stick in an animation (two causes found and a two-line fix tested).
- [riemann-integral-step.md](riemann-integral-step.md) explains an unanswered Wikipedia math desk question about one step in Riemann's 1859 paper and checks the step with numbers to 21 digits.
- [klein-bottle-formula.md](klein-bottle-formula.md) answers an unanswered Wikipedia math desk question about whether a formula describes a one-sided Klein bottle (the checks say the formula describes a torus).
- [prime-set-pairs.md](prime-set-pairs.md) answers a SageMath board question with zero answers about finding every pair of numbers 1 or 2 apart that are built from a chosen set of primes (a Python program confirms both lists in the question with two methods).
- [tensor-grand-sum.md](tensor-grand-sum.md) answers a SageMath board question with zero answers about adding up every entry of a repeated tensor product (the sum equals one number raised to the power n).
- [polar-image-plot.md](polar-image-plot.md) answers a matplotlib forum question with zero replies about an image that lands in the wrong place on a round polar chart (a different drawing command fixes the angle range).
- [scatter-animation.md](scatter-animation.md) answers a matplotlib forum question with zero replies about animating 1000 dots at once (a one-line change to the update step worked in the test).
- [celsius-top-axis.md](celsius-top-axis.md) answers a matplotlib forum question with zero replies about a second axis in degrees Celsius whose ticks sit exactly above the data points.
- [match-stack-error.md](match-stack-error.md) gives a best-guess answer to a Python help forum question with zero replies about a compiler error in a home-made match pattern (the pattern never removes the value being matched).
