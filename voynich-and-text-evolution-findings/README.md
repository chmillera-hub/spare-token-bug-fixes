# Voynich manuscript tests and word evolution experiments

Every file in this folder is a short plain-language page that a visitor can read in a few minutes except the one folder named boring-files which holds only program files.

## Pages to click

- [1-voynich-manuscript-findings.md](1-voynich-manuscript-findings.md) explains what spelling-pattern tests suggest about the order in which scribes wrote the unreadable Voynich manuscript from the early 1400s.
- [2-hiding-a-book-by-splitting-pages.md](2-hiding-a-book-by-splitting-pages.md) shows how much sense is left when a 1000-page biology book is dealt into four piles in four different ways.
- [3-word-evolution-experiments.md](3-word-evolution-experiments.md) shows what happens when text is copied with small mistakes over and over while a reader picks which copies survive.
