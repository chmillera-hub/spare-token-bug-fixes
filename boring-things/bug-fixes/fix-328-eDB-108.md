## The bug

KeyValueStore.list_keys in src/edb/core/keyvalue.py filters with SQL LIKE and does not escape the prefix. list_keys("user_") also returns userX and users and User_2 because _ matches any character and LIKE ignores the case of ASCII letters.

## The fix

list_keys now compares the first characters of the key with the prefix through substr(key 1 n) = prefix. The comparison is exact and case sensitive and has no wildcard. A new file tests/unit/test_unit_kv_prefix_exact.py uses the six keys and the three prefixes from the bug report.
