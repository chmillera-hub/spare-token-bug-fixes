## The bug

web/server/scripts/modules/future-radar.mjs prints a note about expected 404 errors on every data load. The rest of the logging of the module sits behind a debug flag. The note spells the host name hrrrzarrr with one r too many.

## The fix

The note is now printed only when the future-radar debug flag is set and the host name reads hrrrzarr. A new entry in the divergences list of .upstream-sync.json records the difference from the upstream file.

- .upstream-sync.json
