# Program files behind the research pages

This folder holds only program files and a researcher can rerun the tests with these files while a casual visitor can skip this folder.

- The folder voynich-scripts holds four Python files that compute the "next page" scores for the Voynich manuscript and the scripts expect the typed copies named ZL3b-n.txt and IT2a-n.txt and RF1b-e.txt from the site voynich.nu inside a folder named data.
- The folder page-splitting-scripts holds one Python file that deals a public-domain biology book (Project Gutenberg book number 2009) into four piles and computes the confusion scores.
- The folder word-evolution-scripts holds the copy-and-paste evolution programs and the builder for the 10000 commands. The live slider page now sits in the research folder under the name live-program.html so that visitors can find the live slider page.
- The file many_commands_story_order.js in word-evolution-scripts runs with the command "node many_commands_story_order.js A 7" and the setting BONUS=1 in front of the command turns on the bonus for closeness in the story and the setting UNIQ=0.4 turns on the bonus for words that are not repeats.
- The folder mobius-strip-calculations holds the Python files behind the document named The Mobius Strip Picture of Physics.
- The file bible_quotes_builder.py in word-evolution-scripts cuts chosen passages of the World English Bible into short quotes in Bible order for the Bible version of the live program.
- The files word_level_engine.js and word_level_three_bible_selections.js in word-evolution-scripts run the word-level experiment on three Bible selections and the files whole_books_builder.py and words_of_jesus_builder.py cut the Bible text into short quotes.
- The files key_phrase_builder.py and key_phrase_engine.js and key_phrase_three_bible_selections.js in word-evolution-scripts chop the Bible text into key phrases and run the key phrase experiment.
- The folder unanswered-questions-scripts holds three Python files for the number list OEIS A394252: fast_terms.py computes terms exactly (run "python3 fast_terms.py 38") and slow_check.py is a brute-force check for small terms and show_the_30_terms.py prints the 30 earlier terms that add up to the wrongly published term 31.
- The folder unanswered-questions-scripts also holds urljoin_test.py (shows which inputs make the Python function urljoin leave the base website) and sentinel_rejected.py and sentinel_enum.py (a marker that type checkers reject and a marker that type checkers accept) and rdflib_prefix_test.py (shows that rdflib keeps one nickname per web address).
- The folder unanswered-questions-scripts also holds ylim_test.py (rebuilds a matplotlib animation problem and shows the fix) and riemann_step.py (checks a step in Riemann's 1859 paper with numbers) and lawson_check.py (checks whether a formula describes a torus or a Klein bottle).
- The folder unanswered-questions-scripts also holds smooth_pairs.py (finds every pair of numbers 1 or 2 apart built from a chosen set of primes) and grand_sum.py (checks the sum of all entries of a repeated tensor product) and polar_image.py (rebuilds a polar chart problem and tests a fix).
- The folder unanswered-questions-scripts also holds scatter_anim.py (rebuilds a scatter animation problem and tests the fix) and celsius_axis.py (tests a second axis in degrees Celsius) and match_stack.py (shows how the Python compiler handles the value being matched).
- The folder unanswered-questions-scripts also holds dill_parallel.py (parallel work with objects that pickle refuses) and toggle_views.py (switching between two live chart views in one figure) and graph_distance.py (four distance numbers between two graphs drawn in the plane) and layout_test.py (a plot beside an image at the same height) and incircle_check.py (checks a circle squeezed between two lines and an arc).
- The folder unanswered-questions-scripts also holds zstd_frames.py (packs files into one archive as separate frames) and inference_direction.py (four test lines for two type checkers) and fit_uncertainty.py (fit uncertainties from analytical derivatives) and s3_matrices.py (matrices for the six rearrangements of three things) and a folder named spawn-warning-test (silencing an import warning in a child process).
- The folder unanswered-questions-scripts also holds lambert_solve.py (solves an equation with a logarithm) and legendre_q.py (checks special functions against known formulas) and svg_by_colour.py (points along SVG paths of one colour) and cornacchia_cost.py (timings for a sum of two squares algorithm) and srgb_webp.py (what Pillow keeps when saving WebP).
- The folder unanswered-questions-scripts also holds galois_c5.py (Galois group of the eigenvalue field of the 5-cycle graph) and quadruple_link.py (links two formulas for special Pythagorean quadruples) and crypt_heatmap.py (colours cells along a U-shaped outline) and live_plot_speed.py (thinning live data without losing spikes) and echelon_columns.py (identity matrix on chosen columns).
- The folder unanswered-questions-scripts also holds lll_gram.py (what two PARI lattice functions return) and mock_self.py (stand-in methods that use self) and stop_task.py (stopping a running pool job) and protocol_vs_abc.py (what Protocol and ABC classes enforce) and a folder named forward-test (passing input and output to a child process without hanging).
- The folder unanswered-questions-scripts also holds lambda_hints.py (a lambda in an annotation that loses a global name) and chess_move.py (line order inside a try block) and centred_bars.py (histogram bars centered on whole numbers) and curve_mod_p2.py (multiplying a point on an elliptic curve modulo p squared) and graph_orbits.py (counting graphs up to relabeling).
