# Boring things

- The folder named bug-fixes holds the whole shelf of 363 small AI-written bug fixes which means the patch files and one page per fix and the machine-readable lists named index.json and llms.txt and the tools that rebuild the shelf and the notes named HANDOFF for the next working session.
- The folder named research-program-files holds the Python and JavaScript files that produced every number in the research pages.
