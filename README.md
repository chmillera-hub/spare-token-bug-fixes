# Research pages and free bug fixes from Charles and an AI chatbot

Click the folder named 1-research-click-here-first before anything else because that folder holds the pages written for people to read and the other folder holds only program files.

## 1-research-click-here-first

The folder named [1-research-click-here-first](1-research-click-here-first) holds short plain-language pages and documents that a visitor can read in a few minutes each.

- [Voynich manuscript findings](1-research-click-here-first/voynich-manuscript-findings.md) tells who probably made an unreadable book in the early 1400s (five scribes and fifteen calfskins and a castle drawing that points to northern Italy) and how the book was built.
- [Voynich location guess](1-research-click-here-first/voynich-geoguess-clue-sweep.md) guesses where the unreadable book was made from eight drawing clues such as a crossbow archer and forked castle walls and baggy sleeves.
- [Word evolution experiments](1-research-click-here-first/word-evolution-experiments.md) shows what happens when text is copied with small mistakes over and over while a reader picks which copies survive.
- [Try the word evolution program](1-research-click-here-first/try-the-word-evolution-program.md) explains two ways to run a live program with sliders where ten separate agents evolve text from random letters.
- [Three Bible selections in the word evolution experiment](1-research-click-here-first/bible-selections-word-evolution.md) compares what copying agents build from well-known passages and from ten whole books and from only the words of Jesus.
- [Hiding a book by splitting pages](1-research-click-here-first/hiding-a-book-by-splitting-pages.md) shows how much sense is left when a 1000-page biology book is dealt into four piles.
- [The Mobius strip picture of physics](1-research-click-here-first/mobius-strip-picture-of-physics) is a document that pictures strange behaviors in physics with twisted paper ribbons and uses no equations.
- [Writing rules for clear chatbot replies](1-research-click-here-first/writing-rules-for-clear-chatbot-replies.md) is a set of rules with before and after examples that a person can paste into any chatbot.
- [Free bug fixes video](1-research-click-here-first/free-bug-fixes-video.md) points to a short video that shows 363 small ready-made bug fixes for public software projects.

- [Record of the chat behind the research](1-research-click-here-first/record-of-the-chat-behind-the-research.md) lists every request Charles made in his own words and gives the public link to the full chat: https://claude.ai/share/a29d81cb-280d-4d44-a449-e84b9516b4f5

## boring-things

The folder named [boring-things](boring-things) holds program files and patch files and machine-readable lists which means files that programs and software maintainers use and that a casual visitor can skip.

- [The bug fix shelf](boring-things/bug-fixes) holds 363 small AI-written bug fixes for public open source projects and any person or AI model may test a fix and send the fix to the project.
- [Research program files](boring-things/research-program-files) holds the Python and JavaScript files that produced every number in the research pages.

## Who made the pages

An AI chatbot (Claude) wrote the pages and the bug fixes at the request of Charles and no other person has rerun the research tests or reviewed the bug fixes which means every result here is unconfirmed.
